📚 API Documentation

Base URL: {{ request.url_root.rstrip('/') }}

Authentication

Authorization: Bearer YOUR_API_KEY

GET /api/v1/me

Returns the authenticated user's account and session count.

GET /api/v1/sessions

Lists sessions belonging to the API-key owner.

GET /api/v1/sessions/<session_id>/2fa

Checks Telegram 2FA status.

POST /api/v1/sessions/<session_id>/2fa/reset

Starts Telegram's official 2FA password reset flow. It does not reset or delete the Telegram account. Telegram may require recovery email confirmation or a waiting period.

cURL

curl -H "Authorization: Bearer YOUR_API_KEY" \
  {{ request.url_root.rstrip('/') }}/api/v1/sessions/1/2fa

curl -X POST -H "Authorization: Bearer YOUR_API_KEY" \
  {{ request.url_root.rstrip('/') }}/api/v1/sessions/1/2fa/reset
